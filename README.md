# ⚖️ نظام الفحص والتدقيق الذكي للعرائض القضائية (legal-checker-backend API)

نظام برمجي متكامل يعتمد على الذكاء الاصطناعي لتلقي العرائض والمستندات القضائية (PDF / Word) أو النصوص الحرة، واستخلاص البيانات منها وتدقيقها آلياً وفقاً للشروط والضوابط الإلزامية لكل خدمة قضائية.

---

## 🌟 المميزات الرئيسية

* **دعم صيغ متعددة:** قراءة النصوص وتدقيقها من ملفات `PDF` و `DOCX` بالإضافة إلى النصوص المباشرة.
* **المعالجة الذكية للأرقام:** تحويل الأرقام الشرقية/الهندية (`٠-٩`) تلقائياً إلى أرقام غربية (`0-9`) وفصل السلاسل الرقمية الملتصقة بالنصوص لضمان دقة التقاط أرقام الهواتف.
* **تغطية أربعة أنواع من الخدمات القضائية:**
  1. إنشاء دعوى جديدة (`NewLawsuit`).
  2. عريضة طعن بالاستئناف (`AppealPetition`).
  3. طلب أمر على عريضة (`PetitionOrder`).
  4. أمر أداء (`PerformanceOrder`).
* **فحص متعدد الأطراف والمرفقات:** تدقيق بيانات جميع المدعين والمدعى عليهم والمرفقات المذكورة بالنص شخصاً بشخص ومرفقاً بمرفق.
* **مرونة واستقرار الموديلات (Fallback Mechanism):** التنقل الآلي بين عدة نماذج لذكاء Gemini لضمان استمرار الخدمة في حال وجود ضغط على أحد النماذج.
* **مخرجات واضحة باللغة العربية:** إرجاع أسباب الخلل والبيانات الناقصة بأسماء عربية صريحة ومفهومة للمستخدم النهائي دون مصطلحات برمجية إنجليزية.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **Node.js & Express.js:** لبناء السيرفر والـ API.
* **Google GenAI SDK (`@google/genai`):** للربط مع نماذج الذكاء الاصطناعي وتحليل النصوص.
* **Pdf-Parse & Mammoth:** لاستخراج النصوص من ملفات PDF و Word.
* **Multer:** لمقاطعة وتخزين الملفات المرفقة في الذاكرة المؤقتة.
* **CORS:** لتأمين وتبادل الموارد بين النطاقات المختلفة.

## 🚀 كيفية التثبيت والتشغيل المحلي

### 1. المتطلبات الأساسية
* تثبيت [Node.js](https://nodejs.org/) (الإصدار 18 أو أحدث).
* مفتاح API من Google Gemini (`GEMINI_API_KEY`).

### 2. الاستنساخ والتثبيت
```bash
# استنساخ المستودع
git clone [[https://github.com/hamzaanwarali/legal-checker-backend](https://github.com/hamzaanwarali/legal-checker-backend).git](https://github.com/hamzaanwarali/legal-checker-backend.git)

# الدخول لمجلد المشروع
cd legal-checker-backend

# تثبيت الحزم والمكتبات
npm install
3. إعداد متغيرات البيئة
قم بإنشاء ملف .env في جذر المشروع وأضف فيه مفتاح الـ API الخاص بك:
مقتطف الرمز
GEMINI_API_KEY=your_gemini_api_key_here
PORT=10000
4. تشغيل السيرفر
Bash
# تشغيل السيرفر
npm start
سيتم تشغيل السيرفر على المنفذ: http://localhost:10000
📡 دليل استخدام الـ API (API Reference)
تدقيق مستند قضائي
•	URL: /api/analyze
•	Method: POST
•	Content-Type: multipart/form-data أو application/json
المدخلات (Request Body):
الحقل	النوع	الوصف
actionType	string	نوع الخدمة: NewLawsuit, AppealPetition, PetitionOrder, PerformanceOrder
rawText	string	(اختياري) النص الحر المراد فحصه مباشرة
documentFile	file	(اختياري) ملف المستند (.pdf أو .docx)
مثال على الاستجابة (Response Payload):
JSON
{
  "isReadyForSubmission": false,
  "missingFields": [
    "رقم هاتف المدعى عليه الأول"

      "issueDescription": "الاسم المذكور ثنائي فقط ويجب أن يتكون من 3 أسماء على الأقل مع اللقب"
    }
  ]
}
